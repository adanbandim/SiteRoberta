## 🚀 Sobre o Mini Projeto

O objetivo central foi reconstruir a estrutura do site, garantindo que o conteúdo educacional fosse acessível tanto em computadores quanto em dispositivos móveis. 

Embora o foco atual tenha sido a estrutura sólida com **HTML e CSS**, a mudança resultou em um carregamento muito mais rápido e uma experiência de leitura muito superior para os alunos e pesquisadores. 

O site não teve uma consolidação 100%, embora o objetivo tenha sido o foco visual e organização. Ainda faltam coisas como a locação dos arquivos e materiais, bem como a consolidação final da professora em colocar o site no ar. Ainda assim, não deixei de lado para um uso inical para meu portifólio.

---

## 🛠️ Tecnologias e Técnicas Utilizadas

Nesse trabalho, foquei em aplicar conceitos fundamentais de desenvolvimento web moderno:

* **HTML5:** Estruturação semântica de todo o conteúdo.
* **CSS3:** Estilização personalizada sem dependência de bibliotecas externas.
* **Grid Layout:** Utilizado para criar uma malha organizada e alinhada dos elementos acadêmicos.
* **Responsividade (Mobile First):** O site foi pensado para se adaptar perfeitamente a qualquer tamanho de tela.
* **UI/UX Design:** Foco na clareza visual e facilidade de navegação para o público acadêmico.
* **Deployment:** Publicação automatizada via Netlify.
